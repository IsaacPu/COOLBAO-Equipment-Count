## 效率与收益

人工数图的时间花在找点、计算和填表。COOLBAO 先完成规则明确的统计，让技术人员更快进入核对环节。

| 图纸工作量 | 人工统计与填表 | COOLBAO 生成初版表 |
| --- | --- | --- |
| 较小图纸 | 约 **20 分钟** | 约 **15 秒** |
| 较大图纸 | 约 **40 分钟** | 约 **23 秒** |

*当前试用经验；人工含统计与填表，软件计至初版出表，后续人工复核另计。*

### 产品解决了什么

| 能力 | 对技术人员的价值 |
| --- | --- |
| **七类设备统计** | 从 CAD 结构中提取感烟、感温、手报、消报、声光、扬声器与电话分机，减少逐类找点与抄录 |
| **图框与标准层处理** | 按明确范围关联设备、展开楼层，减少手工计算与累加 |
| **来源追溯与疑点核对** | 结合对象来源、位置和楼层复核，保留人工判断依据 |
| **客户 / 泰和安两类导出** | 同一统计版本生成客户 XLSX 或泰和安点位表 XLS，减少重复转填 |

## 我的贡献

这是我在任职期间推进的企业项目实践，覆盖从前期 PoC、业务规则探索，到团队协作与能力整合的产品工作。

**01 · 前期 PoC：把需求变成可操作流程**

拆解真实数图任务，借助 AI 编码工具完成前期原型，打通图纸输入、七类设备试算、核对和逐层表格输出，用具体样例验证产品流程。

**02 · 业务规则：深入理解人工为什么这样数**

学习真实人工数图中的设备配置、图纸识读、标准层和统计口径，将疑点转为设备范围、异常状态、人工复核与表格交付要求。这是我参与产品判断和团队讨论的重要业务基础。

**03 · 研发协作：与 DXF 团队共同制定方案**

结合 PoC 和真实图核对中发现的问题，与 DXF 团队讨论并制定后续方案，明确设备配置、规则处理和验证方式。

**04 · 整合交接：让已有能力进入团队工作流**

在同事已有网站与基础框架上，推动接入对象追溯、图框与楼层规则、人工复核和两类表格导出，并整理实现说明、已知问题与接手材料。

协作分工：我负责产品推进、规则探索及能力整合；同事负责既有网站与基础业务框架；AI 编码工具辅助工程实现。

## 关键产品判断

- **范围先收敛：** 聚焦报警七类，先建立可核对的业务闭环。
- **自动化保留判断入口：** 软件处理明确规则，技术人员处理语义冲突和特殊配置。
- **交付沿用同一份数量：** 客户表和泰和安表从同一统计版本导出，保持口径一致。

> 把专业人员的工作经验，转成产品可以执行、团队可以讨论、结果可以验证的要求。
